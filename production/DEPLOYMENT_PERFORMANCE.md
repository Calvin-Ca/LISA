## 指标解释与当前容量结论

- `LISA_MAX_CONCURRENCY=1` 表示同一时刻最多有 1 个请求进入 GPU 推理。
- `LISA_MAX_QUEUE_SIZE=8` 表示最多有 8 个请求等待，不代表 GPU 并发为 8。
- 稳态吞吐应引用预热后的正式压测结果，当前历史基线约为
  2.5～2.6 req/s。
- 记录版增加了 SQLite、原图和 mask 写入，当前只有一次真实请求，不能认定
  它仍然保持历史吞吐，也不能用单次 1.29 秒响应宣称吞吐只有 0.78 req/s。
- 在完成记录版并发回归前，当前部署适用于可信内网、人工交互和低频试用，
  不对高频批处理或多路视频流承诺正式容量。
- 提高客户端并发只会增加排队；要提高 GPU 稳态吞吐，优先考虑多 GPU
  横向扩展或经过专项验证的批处理，不增加 Uvicorn worker 重复加载模型。
